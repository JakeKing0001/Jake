# Architecture Decision Records

Gli ADR registrano decisioni architetturali difficili da cambiare. `Accepted` descrive una
scelta già vincolante; `Proposed` consente ancora benchmark o threat-model prima di adottarla.
Una decisione sostituita non viene cancellata: riceve stato `Superseded` e un link al nuovo ADR.
